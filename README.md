# Sales Analysis Dashboard

An interactive Excel dashboard designed to analyze sales performance and generate actionable business insights.

## Key Features

- Total Revenue analysis
- Total Orders
- Average Days Between Order and Delivery
- Average Customer Spending
- Revenue by Occasion
- Revenue by Category
- Revenue by Hour
- Monthly Revenue Trends
- Top Products by Revenue
- Top Cities by Orders
- Interactive Order Date and Delivery Date slicers
- Power Pivot & DAX measures
- PivotTables and PivotCharts

## Tools & Technologies

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- PivotTables
- PivotCharts
- Slicers
